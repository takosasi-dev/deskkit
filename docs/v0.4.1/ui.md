## やったこと

1. **サイドバーを詰めた**(`deskkit/ui/main_window.py`)
   - 1 行の高さを 40 → 32px(`NAV_ITEM_HEIGHT`)。上下の余白 18/14 → 14/10、行の間 2 → 1px、ロゴ 34 → 32px、見出しと区切りの余白を詰めた。
   - 窓 1220×800 で、ロゴ・DeskKit・版から「ログ」までスクロールなしで収まる。いちばん下の PlugSave を選んでもスクロールしないので、見出しは切れない。
   - 1000×660 では今までどおりサイドバーだけスクロールし、選んだ項目が見える位置まで動く。
   - 選択中の背景の左の縦棒は、行の高さに合わせて長さを決めるようにした(固定の 10px 余白だと 32px の行では短すぎるため)。
2. **ホームのカードを詰めた**
   - 1220px で 3 列(`CardGrid`・`card_columns`)。中身の幅が 3 列 × 270px に足りなければ 2 列に戻す(1000px では 2 列)。
   - カードは 2 段: 1 段目にアイコン・名前・状態(小さいピル)・スイッチ、その下に一言(右端まで使う。入りきらなければ折り返す)。2 段目に状態文・再起動(停止中だけ)・開く。
   - 高さは約 176px → 約 108px(6 割強)。ホーム全体の高さは 2675px → 1424px(実画面の 120% 表示の撮影で 53%)。
   - 状態文が 1 行に入りきらないときは末尾を「…」にして、全文をツールチップに出す(`widgets.ElidedLabel`)。1220px の実画面では今ある状態文はすべて切れずに入った。
   - カード全体のクリックで開く動作・スイッチ・開くボタンはそのまま。
3. **利用状況の空の欄を畳んだ**(`deskkit/ui/usage_page.py`)
   - 選んだ期間に記録が 1 件も無いモジュール(全指標が 0、または集計できる指標が無い)は、グラフも表も出さず、下の 1 枚にまとめて 1 行ずつ(アイコン・名前・「この期間の記録はありません」)。
   - 記録のあるモジュールを上に(中の順は catalog のまま)。グラフと表のどちらの表示でも同じ。
4. **表示名**
   - 「設定の世代」「設定の読み込み・戻す」の確認に出る `backup.summary` を表示名にした(「有効なモジュール: ModeShift, DropSort」「DropSort: 3 ルール」)。
   - ローダーのログの文言を表示名にした(「ClipShelf を起動しました」「… の起動に失敗しました」「… を止めるときに例外」「… を停止中にしました: 理由」)。ロガー名(`host.loader`)とログの列の見た目は変えていない。
5. **FadeStack の高さ**(`deskkit/ui/widgets.py`)
   - `sizeHint`・`minimumSizeHint`・`heightForWidth` を今表示しているページだけから決める。ページを切り替えたら `updateGeometry()`。
   - 隠れているページの高さで短いページのカードが縦に伸びることはなくなる。PagePress・MojiFix の回避策には触っていない(MojiFix の `_fit_stack` はこのままでも同じ結果になる)。
6. **実画面で確かめた**(本物の Windows の描画、`theme.apply`・`host.show_window()`・`win.grab()`、一時 `DESKKIT_HOME`、DropSort の監視先は一時フォルダ)
   - ダーク・ライト × 1220×800・1000×660 で、ホーム・利用状況(グラフと表)・PlugSave・設定・ログを撮った。

## 仮に決めたこと(利用者に確かめたいこと)

- **ホームの見出しの状態ピルを折り返すようにした**(`widgets.FlowLayout`、`Hero.pills`)。最小の幅 1000px で、ホームの見出しのピル(前面・自動起動・DPI)が 1 行に並びきらず、ページ全体が横にはみ出していた(2 列に戻す判定も効かなかった)。§3 A の範囲の外だが、2 列に戻すために必要だったので直した。全モジュールの見出し(`Hero`)に効く。幅が足りるときの見た目は今までと同じ。
- ホームのカードの状態のピルを、名前の横の小さい版(`StatusPill(compact=True)`)にした。2 段目を状態文に広く使うため。
- 停止中の「再起動」ボタンは、文字のボタンからアイコンのボタン(ツールチップ「再起動」)にした。
- 利用状況で、集計できる指標が無いモジュール(`usage()` が空)も「この期間の記録はありません」の 1 行にまとめた(前は「まだ集計できるデータがありません」のカード)。

## 本体への提案(触ってよいファイルの外なので直していない)

- `deskkit/host.py` `after_hotkey_registration`: 「登録できなかったホットキーがあります」の通知とログに、ホットキーの完全名(`host.quick`・`clipshelf.palette` など)が出る。`hotkey_label` と表示名(「ClipShelf パレットを開く(Ctrl+Alt+V)」の形)にすると、内部名が画面に出なくなる。
- `deskkit/host.py:428`: IPC の返事「`{name}` は無効または停止中です」が内部名。`catalog.info(name).title` にするとよい。
- (担当 B 向けの参考)撮影中のログに、DropSort の「基準線を記録しました: 0 件 (パス)」とパスが出ていた(§3 B-1 の対象)。
