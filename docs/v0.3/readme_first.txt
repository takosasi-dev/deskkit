DeskKit(QOL ツールキット) v0.3.0
==================================

■ これは何?
  PC を快適にする7つの道具を1つにまとめた常駐アプリです。

  いつも裏で動いて助けてくれる道具
  ・ModeShift   「ゲーム」「勉強」などのモードを作り、電源プラン・音量・アプリの起動/終了を1クリックで切り替え
  ・DropSort    ダウンロードが終わったファイルを、決めたルールで自動的にフォルダへ整理
  ・LayoutKeep  モニタの抜き差しやスリープ復帰で崩れたウィンドウ配置を元に戻す
  ・ClipShelf   コピーしたテキストの履歴(暗号化して保存)と定型文。Ctrl+Alt+V で呼び出し

  困ったときに開いて使う道具(v0.3.0 で追加)
  ・SendPrep    写真や動画を人に送る前に整えます。位置情報などの隠れた情報を消し、
                送り先のサイズに収め、見せたくない文字を塗りつぶした「別のファイル」を作ります。
                元の写真や動画は変えません。
  ・PcCheckup   「重い」「ネットが遅い」「容量が足りない」のボタンを押すと、原因の候補と
                次にやることを教えてくれます。PC の設定は変えません。
  ・TwinSweep   そっくりな写真をまとめて、いちばん良い1枚を提案します。
                残りは確認してから「ごみ箱」へ送るので、あとから元に戻せます。

■ 使い方
  1. DeskKit.exe をダブルクリックします(インストール不要・管理者権限不要)。
  2. 開いた画面で、使いたい道具のスイッチをオンにします。最初はすべてオフです。
  3. オンにした道具の画面で設定します。
     いつも動く4つの道具は、最初は安全のため「試運転」で動きます。実際にファイルやウィンドウを動かす前に、
     「何をする予定か」だけを表示するので、確認してから「本番」に切り替えてください。
     困ったときの3つの道具は、あなたがボタンを押したときだけ動きます。
  4. 画面を閉じても、画面右下のトレイで動き続けます。アイコンをクリックすると画面が開きます。
     終了するときは、トレイのアイコンを右クリック →「終了」。

■ 写真や動画を送る前に(SendPrep)
  ・SendPrep の画面に写真や動画をドラッグして、「整える」を押します。
    できたファイルは、元のファイルと同じフォルダに「(元の名前)_share」という名前で作られます。
  ・SendPrep の設定で「エクスプローラーの『送る』に追加」をオンにすると、
    ファイルを右クリック →「送る」→「SendPrep で整える」から渡せます(一度に 200 個まで)。
    DeskKit を起動していなくても、自動で起動して受け取ります。
  ・動画を初めて整えるときは、準備に数秒かかります(2回目からはすぐ始まります)。

■ 安心のために
  ・インターネットへの接続は、新しい版の確認とダウンロード(GitHub)だけです。「設定」→「アップデート」でオフにできます。
    SendPrep・PcCheckup・TwinSweep はインターネットに接続しません。
  ・キーボードの入力を盗み見る仕組み(フック)は使いません。
  ・ゲームや全画面の動画を見ている間は、画面に割り込む操作をしません。
    ゲームの exe 名を「設定」画面の「ゲーム・全画面中の安全装置」に登録しておくと確実です。
  ・ファイルを勝手に削除しません。DropSort の移動や LayoutKeep の配置変更は「元に戻す」で戻せます。
    TwinSweep や PcCheckup が片づけるファイルは、確認のあと「ごみ箱」へ送るだけです。
    USB メモリやネットワーク上のファイルは、ごみ箱に入らないので送らずにそのまま残します。
  ・ログには、ファイルの名前や置き場所、写真の中の文字を書きません。

■ 便利な使い方
  ・Ctrl+Alt+Space で「クイックアクション」が開きます。「ゲーム」「配置」「元に戻す」などと打って Enter。
  ・「利用状況」ページで、それぞれの道具をどれくらい使っているかをグラフで見られます。
  ・新しい版が出ると通知が出ます。「更新して再起動」を押すだけで入れ替わります(前の版にも戻せます)。
    DeskKit.exe は書き込みできるフォルダ(ドキュメントやデスクトップ)に置いてください。
  ・「設定」で、テーマ(ダーク/ライト/Windows に合わせる)の変更、設定のバックアップ/復元ができます。
    設定は変えるたびに自動で残るので、「設定の世代」から前の状態に戻せます。
  ・画面共有や録画の前は、トレイの「一時停止」(30分/1時間/再開するまで)で自動の動きをまとめて止められます。
  ・ゲームや全画面の動画を見ている間の通知は、終わってからまとめて表示します。
  ・うまく動かないときは「設定」→「診断レポートをコピー」。ユーザー名や中身を含まない状態の要約がコピーされます。

■ 初回起動時の注意
  Windows SmartScreen の「PC を保護しました」が出た場合は、「詳細情報」→「実行」を押してください
  (署名の無い個人製ソフトのため表示されます)。
  v0.3.0 から DeskKit.exe が大きくなりました(写真・動画を扱う部品を同梱したため)。
  起動の速さや、何もしていないときの動きの軽さはほとんど変わりません。

■ 消し方
  1. トレイの「終了」で止めます。
  2. 自動起動をオンにしていた場合は、先に「設定」画面でオフにします。
     SendPrep の「送る」への追加をオンにしていた場合も、先にオフにします。
  3. DeskKit.exe と、次の2つのフォルダを削除します。
       %APPDATA%\DeskKit
       %LOCALAPPDATA%\DeskKit
